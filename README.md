# Проект «SAPERR» — ДЗ №2

- **ФИО:** "Логинов Сергей Евгеньевич"
- **Группа:** "Б9125-02.03.01 СЦТ 1"

Классическая браузерная игра «Сапёр» (поле 9 на 9, 10 мин)

## В проекте:

- **Звуковые эффекты:** добавил озвучку на встроенном в браузер Web Audio API (без загрузки внешних mp3-файлов). Есть отдельные звуки для клика по клетке, раскрытия большой пустой зоны, установки флага, взрыва, победной мелодии, а также звуки для кнопок меню. Звук можно включить\выключить при помощи соответчтвующей кнопки.
- **Сохранение игры:** прогресс сохраняется в `localStorage`. При загрузке файл сохранения проходит проверку на целостность и правильность данных — если его повредить или подменить, игра не вылетит с ошибкой, а просто начнет новую игру.
- **Тесты:** написал 6 юнит-тестов на Vitest (проверка генерации поля, количества мин, безопасной зоны при первом клике, подсчёта цифр вокруг мин, условия победы и проверки данных сохранения).
- **Интерфейс:** при победе запускается салют через библиотеку `canvas-confetti`, есть счётчик флагов и подсветка экрана при проигрыше или выигрыше.
